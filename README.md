# Frontend — СПбГУПТД Mini App

React Telegram Mini App: студенческий календарь, предметы, оценки, калькулятор.

## Запуск локально

```bash
cd frontend
npm install
cp .env.example .env
# В .env пропиши VITE_API_URL (адрес бэкенда)
npm run dev
```

Откроется на `http://localhost:5173`.

В режиме разработки API использует моковый `X-User-Id: 12345`.
Внутри Telegram автоматически берётся реальный ID юзера.

## Структура

```
src/
├── api/
│   └── client.js          REST API клиент
├── components/
│   ├── Header.jsx         Шапка с приветствием + аватар
│   ├── Calendar.jsx       Месячный календарь с точками событий
│   ├── EventCard.jsx      Карточка события
│   ├── SubjectCard.jsx    Карточка предмета с оценкой
│   ├── BottomNav.jsx      Нижняя навигация (4 вкладки)
│   └── Sheet.jsx          Bottom sheet (модалка снизу)
├── pages/
│   ├── CalendarPage.jsx        Главная: календарь + ближайшие
│   ├── EventForm.jsx           Форма события (в Sheet)
│   ├── SubjectsPage.jsx        Список предметов
│   ├── SubjectDetailPage.jsx   Оценки + калькулятор + прогноз
│   ├── GradesPage.jsx          Сводка по всем оценкам
│   └── ProfilePage.jsx         Профиль и настройки уведомлений
├── App.jsx
├── main.jsx
├── styles.css             Базовые стили + переменные темы
├── components.css         Стили компонентов
└── utils.js               Утилиты: даты, типы событий, haptic
```

## Дизайн

Цветовая палитра подобрана под фасад СПбГУПТД:
- Тёплая бежево-золотистая (`#f0d89a`) — акценты
- Тёмный фон с фотографией универа + градиент
- Стеклянные карточки (`backdrop-filter: blur`)
- Типы событий: 🔴 экзамен / 🟢 зачёт / 🟣 контрольная / 🟡 лекция

## Сборка для деплоя

```bash
npm run build
```

Готовая папка `dist/` загружается на:
- **Vercel** (рекомендую) — просто подключаешь репозиторий, авто-деплой
- **Netlify** — drag-n-drop папки dist
- **GitHub Pages**

После деплоя URL добавить в @BotFather:
```
/setdomain → выбрать бота → ввести https://your-app.vercel.app
/newapp → создать Mini App с этим URL
```

✓ 5 типов событий (экзамен, зачёт, контрольная, лекция, другое)
✓ Привязка событий к предметам
✓ Предметы с настраиваемым порогом зачёта
✓ Калькулятор оценок (5-балльная) с весами
✓ Прогноз «сколько нужно набрать»
✓ Сводка средней оценки по всем предметам
✓ Настройка частоты уведомлений (3,1 / 7,3,1 / и т.д.)
✓ Telegram WebApp интеграция (haptic, тема, юзер)
✓ Адаптивно под мобильные экраны
